# 教学语言规范 Skill

**paeg-teaching-language-skill** 是 PAEG 教学智能体生态中的语言规范技能：为中文教学物料（课件、讲义、教案、试题、逐字稿）提供**可执行的书面语规范**与**自动检查工具**。

规范依据：

- 《中华人民共和国国家通用语言文字法》
- **GB/T 15834—2011《标点符号用法》**
- **GB/T 15835—2011《出版物上数字用法》**
- 《普通高中英语课程标准（2017 年版 2020 年修订）》的术语体系
- 教学语言研究成果：教学语言应具备科学性、规范性、教育性、启发性、简明性

## 解决什么问题

AI 生成的教学文本常见五类不合规：

1. **口语化**：才有、要看、谈不上、查不到、才是、一下子。
2. **比喻替代定义**：词是建筑材料、谓语动词的三个包袱、词类是身份而成分是岗位。
3. **笔记体**：记住……就……、必记点、无主句祈使式讲解。
4. **标点不规范**：并列词语用斜杠或加号、半角标点混入中文、标题末尾加句号。
5. **数字与层级混用**：第1讲与第一讲混用、概数用阿拉伯数字。

本技能把这些要求变成**规则文件 + 违禁词库 + 检查器 + 改写照**，可复核、可复现。

## 快速开始

```bash
# 检查（只诊断，不改文件）
python -m paeg_teaching_language check 讲义.md

# 输出 JSON 报告
python -m paeg_teaching_language check ./材料 --json 报告.json

# 批改（默认预览，加 --write 才写回）
python -m paeg_teaching_language fix 讲义.md --write

# 自测与演示
python -m pytest tests -q
python demo.py
```

## 设计原则

1. **规则可核查**：每条规则都能落到一个可枚举的检查项，检查报告能给出文件、位置与命中内容。
2. **词库可扩展**：违禁词与替换表放在 `data/*.json`，学科与机构可自行增补。
3. **自动检查不等于终审**：比喻、语体、逻辑连贯仍需人工判断，技能明确要求两步流程。
4. **不误伤正常表达**：英文例句及其译文不纳入第二人称与并列连接符号检查。
5. **零第三方依赖**：检查器只用 Python 标准库，便于在任何教学环境运行。
