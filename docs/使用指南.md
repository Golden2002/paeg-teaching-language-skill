# 使用指南：把规范落到各类教学物料

> 本指南说明在课件、讲义、教案、试题与逐字稿中如何执行《教学语言规范》。
> 通用流程：**先诊断，再改写，后复核**。诊断与复核使用本技能的检查器。

```bash
# 诊断
python -m paeg_teaching_language check 材料目录
# 机械修复（预览）
python -m paeg_teaching_language fix 材料目录
# 写回
python -m paeg_teaching_language fix 材料目录 --write
```

## 一、课件（PPT）

| 位置 | 要求 | 常见错误 |
|---|---|---|
| 标题 | 名词短语或短句，**末尾不加句号**，不超过 18 字 | 标题写成完整句并加句号；标题用箭头、斜杠堆叠 |
| 副标题 | 补充说明，末尾不加句号 | 副标题写成讲解句 |
| 正文条目 | 完整陈述句；每页不超过 150 字 | 提纲式短语、无主句祈使句 |
| 例句 | 英文原样，中文译文另起一行 | 译文夹在英文句中 |
| 表格 | 表头规范完整；单元格可用短语 | 表头用符号或缩写 |
| 备注（演讲者视图） | 写清讲授方式与提问设计，可用口头语 | 备注写成正文；备注含口语词而不自知 |

**注意**：课件的备注（讲稿提示）可以保留课堂口语，但若备注会随课件公开，仍应规范。

## 二、讲义

1. **知识讲解**段落一律使用陈述句，概念先界说再展开。
2. **例句**统一编号，英文与译文分列，译文后可用括号标注成分。
3. **对比辨析**使用表格；表头写清比较维度（如"判断依据"）。
4. **小结**用完整句子，不用"记住……就……"。
5. 全文术语一致：同一概念只用一种名称（如统一写"宾语补足语"，不混用"宾补"）。

## 三、教案

| 栏目 | 规范要求 |
|---|---|
| 教学目标 | 用"能够……"表述，可检验；不使用"了解""掌握"等不可测动词单独成条 |
| 学情分析 | 客观陈述学生已有基础与困难，不用夸张评价 |
| 教学过程 | 环节、时间、教师活动、学生活动、设计意图分栏；时间用阿拉伯数字 |
| 板书设计 | 结构清楚，标注生成节奏 |
| 作业分层 | 分层名称统一（基础、提升、挑战），每层写清完成标准 |

## 四、试题与解析

1. 题干完整，指令明确：`Fill in the blanks with the proper form of the given word.`
2. 答案与解析分列；解析说明**判断依据**，而不是只给结论。
3. 解析中不使用"坑""陷阱""秒杀"等词，改用"常见错误""判断依据"。
4. 选项编号统一使用大写字母；题号使用阿拉伯数字。

## 五、逐字稿

1. 逐字稿记录课堂口语，**允许口语表达**，但需遵守两点：
   - 讲解性语句（概念、规则、依据）应规范；
   - 不出现网络语与营销语。
2. 用标注区分类型：【师】教师话术、【生】预设学生回答、【板书】板书动作、【PPT】翻页、【设计意图】设计说明。
3. 时间标记统一格式：【00:00-04:00】。
4. 检查时可用 `--kind body` 的默认规则；逐字稿中的口语词若确为课堂用语，可在报告中标注为"经确认保留"。

## 六、团队协作建议

1. **建立本学科词库**：在 `data/forbidden_words.json` 基础上追加学科专用违禁词，用 `--config` 加载：
   ```json
   {"forbidden": [{"word": "语法点", "category": "口语化", "advice": "改为“语法项目”"}]}
   ```
2. **把检查纳入交付流程**：物料定稿前必须运行检查器并附报告。
3. **保留改写记录**：把返修中的典型误写补入 `docs/正误对照100例.md`，形成机构自己的语料。
4. **区分"自动检查"与"人工终审"**：前者覆盖可枚举项，后者负责比喻、逻辑与学科准确性。

## 七、复核清单（交付前）

- [ ] 已运行检查器，违禁项为零（或已逐条确认保留）
- [ ] 已人工通读，确认无比喻替代定义
- [ ] 已确认标题、副标题末尾无句号
- [ ] 已确认层级编号（第几讲）全文一致
- [ ] 已确认术语全文一致，首次出现有界说
- [ ] 已确认例句译文无翻译腔
- [ ] 已附检查报告
