# 正误对照 100 例

> 说明：本表按问题类别编排，可检索、可模仿。每例给出**误写**、**正写**与**依据**（对应《教学语言规范》的规则编号）。
> 例句取自真实教学物料的返修记录，学科场景为高中英语语法课。
