# 中文教学语言规范

> 本文件是教学物料（课件、讲义、教案、试题、逐字稿）的语言执行标准。
> 所有中文文本均须逐条对照本文件修改，改完后用本技能自带检查器复核：
> `python -m paeg_teaching_language check <文件或目录>`

## 一、制定依据

1. 《中华人民共和国国家通用语言文字法》：教学应当使用国家通用语言文字，用语用字应当规范。
2. **GB/T 15834—2011《标点符号用法》**：点号与标号的用法。
3. **GB/T 15835—2011《出版物上数字用法》**：汉字数字与阿拉伯数字的选用。
4. 《普通高中英语课程标准（2017 年版 2020 年修订）》：术语以课标与通行教材用语为准。
5. 教学语言研究成果：教学语言应具备**科学性、规范性、教育性、启发性、简明性**。

## 二、语体定位

教学物料属于**教学书面语**，归入说明性科技语体，特征是客观、准确、简明、术语化。
它既不是文学语体，也不是课堂口语的逐字记录，因此：

- 不使用比喻替代概念定义；
- 不使用口语词、方言词、网络语；
- 不使用课堂上的招呼语与口头禅。

## 三、十条硬性规则

### 规则 1　概念一律使用定义式表述

概念首次出现时必须界说，句式用"……是……""……指……""……称为……"。

- 误：词是建筑材料，名词、动词和形容词各管一摊。
- 正：词是最小的能够独立运用的语言单位，名词、动词、形容词分别表示事物、动作与性质。

### 规则 2　禁用口语词与网络语

| 类别 | 禁用示例 |
|---|---|
| 口语化 | 各管一摊、抱团、认全、一眼、一下子、说白了、其实吧、没必要、咱们、才有、要看、谈不上、查不到、才是、自带 |
| 笔记体 | 记住……就……、只要……就、必记、抓……二字、先看……再看…… |
| 网络与营销 | 搞定、干货、坑、抓手、秒懂、神器、必杀、无敌、史上最全、提分神器 |
| 含糊评价 | 超级、特别特别、非常好用、绝对正确 |

### 规则 3　讲解一律使用陈述句

不使用无主句与祈使句，不使用第二人称。

- 误：先找主语，再判关系。
- 正：判断时应当先找出逻辑主语，再判断主动或被动关系。
- 误：记住连词就记住了从句。
- 正：从属连词是识别状语从句类型的主要标志。

### 规则 4　术语规范且前后一致

统一使用学科通行术语；首次出现给出界说；全篇不得同一概念使用两种名称。
示例（英语学科）：句子成分、主语、谓语、宾语、表语、定语、状语、宾语补足语、同位语、谓语动词、非谓语动词、不定式、动名词、现在分词、过去分词、逻辑主语、主动关系、被动关系、时态、语态、语气、屈折变化、主谓一致。

### 规则 5　标点符号遵循 GB/T 15834—2011

| 情形 | 要求 | 误例 | 正例 |
|---|---|---|---|
| 并列词语之间 | 用顿号或连词 | 主语／谓语／宾语 | 主语、谓语、宾语 |
| 并列词语之间 | 不用加号 | 位置＋关系＋功能 | 位置、关系与功能 |
| 分句之间 | 用逗号 | 先找主语；再判关系 | 先找主语，再判断关系 |
| 并列分句之间 | 内部已有逗号时用分号 | 先找主语，再判关系，最后定时间 | 先找出逻辑主语，再判断主动或被动关系；时间先后则最后判断 |
| 总说与分说之间 | 用冒号 | 成分有八种，主语、谓语…… | 句子成分共有八种：主语、谓语…… |
| 直接引语 | 用引号，引文独立成句时句末点号在引号内 | 他说快一点走。 | 他说："快一点走。" |
| 篇名、书名 | 用书名号 | 学习"劝学" | 学习《劝学》 |
| 破折号 | 占两格，用于解释；不与"即"连用 | 三种形式——即 to do、doing、done | 三种形式——to do、doing、done |
| 省略号 | 六点，不与"等"连用 | ……等等 | …… |
| 标题末尾 | 不加句号 | 词在句子中各司其职。 | 词在句子中各司其职 |
| 层次序数 | 一、／（一）／1.／（1） | 第1，第2 | 第一，第二 |

### 规则 6　数字用法遵循 GB/T 15835—2011

1. 计量与编号使用阿拉伯数字：45 分钟、第 12 页、第 5 题。
2. 层级编号内部保持一致：教学材料通常写作"第一讲、第二讲……第十讲"。
3. 概数使用汉字数字：三四分钟、十几年、十几个。
4. 数值范围使用一字线：第 1—3 讲。
5. 同一层级不得混用两种数字形式。

### 规则 7　中西文混排

1. 外语术语与语法形式直接使用，首次出现时给出中文名称。
2. 中文句子内部使用中文全角标点；外文原句内部使用西文半角标点。
3. 中文与外文之间不额外插入空格；公式与例句单独成行时前后留空。

### 规则 8　句长与结构

1. 单个句子一般不超过 40 字，避免多重定语与长串并列。
2. 一个句子只表达一个要点；要点较多时拆分为数句。
3. 规范使用"的、地、得"：定语用"的"，状语用"地"，补语用"得"。

### 规则 9　译文与人称

1. 例句译文须符合汉语表达习惯，不得出现翻译腔。
2. 讲解使用第三人称客观表述；需要指称学习者时统一使用"学生"或"我们"。
3. 不使用第二人称祈使句。

### 规则 10　立场与表述

1. 不夸张、不营销、不承诺分数。
2. 涉及易错点时用"需要注意""常见错误是"等客观表述，不用"坑""陷阱"等词。

## 四、五项特性自查

| 特性 | 含义 | 自查问题 |
|---|---|---|
| 科学性 | 概念准确，判断有据 | 这个说法在学科上成立吗？ |
| 规范性 | 用语用字合乎国家标准 | 标点、数字、术语是否规范？ |
| 教育性 | 内容健康、有引导作用 | 是否有助于学生形成正确认识？ |
| 启发性 | 引导思考，而非只给结论 | 是否说明了判断依据？ |
| 简明性 | 言简意赅，无冗词 | 能否删去不影响意思的字词？ |

## 五、执行流程

1. **诊断**：`python -m paeg_teaching_language check <文件或目录>`
2. **机械修复**：`python -m paeg_teaching_language fix <文件> --write`
3. **人工终审**：对照 `正误对照100例.md` 逐段改写比喻、无主句与超长句。
4. **复核**：再次运行检查器，确认违禁项为零；对"第二人称"等告警结合上下文判断。
5. **交付**：随物料附检查报告，说明检查项、命中数与处理结论。
