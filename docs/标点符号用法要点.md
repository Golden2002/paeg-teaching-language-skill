# 标点符号用法要点（依据 GB/T 15834—2011）

> 面向教学物料编写的要点摘录与示例。规则以大字号列出，示例取自课件与讲义的真实场景。

## 一、点号：顿号、逗号、分号

1. **顿号用于句子内部并列词语之间**，是句子内部最小的停顿。
   - 正：主语、谓语、宾语、表语都属于句子成分。
   - 误：主语／谓语／宾语、表语都属于句子成分。
2. **并列性的谓语、补语之间不用顿号，用逗号。**
   - 正：他的讲解清楚，简洁，易懂。（并列谓语）
   - 误：他的讲解清楚、简洁、易懂。
3. **并列词语中已使用连词"和、或、及、与"时，不再用顿号。**
   - 正：名词、动词与形容词都属于实词。
   - 误：名词、动词、与形容词都属于实词。
4. **相邻数字表示约数时不用顿号。**
   - 正：三四分钟即可完成。
   - 误：三、四分钟即可完成。
   - 但表示两种并列事物时要加顿号：一、二年级都要开设该课程。
5. **并列的引号、书名号之间不用顿号。**
   - 正：《劝学》《师说》都是课文。
6. **分号用于复句内部的并列分句之间；分句之间没有逗号时不用分号。**
   - 正：语言用来抒情达意；文字用来记言记事。
   - 正：判断句子成分时先找出谓语，再分析其他成分；时间先后则最后判断。
   - 误：先找主语；再判关系。
7. **小的并列用顿号，大的并列用逗号；分句间小的用逗号，大的用分号。**

## 二、点号：冒号、句号、问号、叹号

1. **冒号用于总说之后引出分说，或提示性词语之后引出内容。**
   - 正：句子成分共有八种：主语、谓语、宾语、表语、定语、状语、宾语补足语、同位语。
   - 提示性词语后可改用逗号：大量事实证明，朗读有助于语感形成。
2. **冒号的提示作用须管到句末，不能只管句中一部分。**
   - 误：本学期开设三门课程：语文、数学，另有选修课两门。
3. **"某某说"在句首用冒号，在句中用逗号，在句末用句号。**
4. **标题末尾不加句号**（公文标题、课件标题、讲义标题一致）。
5. **无疑问语气不用问号**：我不知道他什么时候到。为什么要这样判断，需要说明依据。
6. **选择问句只在句末用一个问号**，中间用逗号。
7. **倒装句中问号、叹号放在句末**：怎么了，你？

## 三、标号：引号、括号、破折号、省略号、书名号

1. **引文独立成句时，句末点号放在引号内**；引文不完整或只作句子一部分时，点号放在引号外。
   - 正：他说："先找出逻辑主语。" ／ 他强调"判断依据是功能"，而不是词形。
2. **引文之内再有引文时，外层用双引号，内层用单引号。**
3. **需要强调的特定含义词语加引号**：主语、谓语等成分由词"充当"，而非词本身固有。
4. **括号**：句内括号紧贴被注释词语，末尾不加点号（问号、叹号除外）；句外括号在句末标点之后。
5. **破折号占两个字位置，用于解释或话题转换；不与"即""也就是"连用。**
   - 误：非谓语形式共三种——即 to do、doing、done。
   - 正：非谓语形式共三种——to do、doing、done。
6. **省略号六个点，不与"等"连用。**
   - 误：短语、从句、分词……等。
7. **书名号用于书名、篇名、报刊名、影视剧名**；课程名、活动名、栏目名用引号。
   - 正：学习《劝学》；参加"校园读书节"。

## 四、标点位置与层次序数

1. 句号、问号、叹号、分号、冒号、逗号、顿号各占一个字格，紧挨文字。
2. 引号、括号、书名号的前半边不出现在行末，后半边不出现在行首。
3. 省略号与破折号占两个字格，不可拆散使用。
4. **层次序数格式**：第一层"一、"，第二层"（一）"，第三层"1."，第四层"（1）"。
5. 用"首先""其次""再次"或"第一""第二"表示顺序时，其后用逗号。
6. 中文文本内一律使用全角标点；外文原句内使用半角标点。

## 五、教学物料中的高频错误清单

| 错误写法 | 正确写法 | 说明 |
|---|---|---|
| 主语/谓语/宾语 | 主语、谓语、宾语 | 并列词语用顿号 |
| 位置 + 关系 + 功能 | 位置、关系与功能 | 并列不用加号 |
| 词进入句子,才有成分 | 词进入句子，才有成分 | 中文用全角逗号 |
| 三个包袱——即时态、语态 | 三个包袱——时态、语态 | 破折号不与"即"连用 |
| 分词、动名词……等 | 分词、动名词…… | 省略号不与"等"连用 |
| 八种成分。 | 八种成分 | 标题末尾不加句号 |
| 记住连词就记住了从句。 | 从属连词是识别状语从句类型的主要标志。 | 讲解用陈述句 |
